# logos/

Place all HENU OS logo files here.

## Required Files (for build validation to pass)

| File | Path | Used By |
|---|---|---|
| Primary SVG | `svg/henu-logo-primary.svg` | Installer, GDM |
| White SVG | `svg/henu-logo-white.svg` | Plymouth, dark backgrounds |
| Black SVG | `svg/henu-logo-black.svg` | Light backgrounds |
| Wordmark SVG | `wordmark/henu-wordmark.svg` | About screen, docs |
| PNG 512px | `png/henu-logo-512.png` | App icons, package |
| PNG 256px | `png/henu-logo-256.png` | Desktop icons |
| PNG 128px | `png/henu-logo-128.png` | Panel, taskbar |
| PNG 64px | `png/henu-logo-64.png` | Notification icons |
| PNG 32px | `png/henu-logo-32.png` | Favicon |
| PNG 16px | `png/henu-logo-16.png` | Tray icons |

## Export Guidelines

- SVG files must be 100% vector (no embedded rasters).
- PNG files must be exported at exactly the named resolution.
- All files must have transparent backgrounds.
- Color mode: sRGB.

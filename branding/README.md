# HENU OS 3.0 — Branding Directory

This directory contains all official HENU OS visual identity assets.

**Every file placed here becomes part of the HENU OS brand.**

---

## Directory Map

```
branding/
│
├── logos/                  ← Official HENU OS logo files
│   ├── primary/            ← Full-color primary logo
│   ├── secondary/          ← Alternate color variants
│   ├── wordmark/           ← Text-only wordmark logo
│   ├── monochrome/         ← Single-color versions (white/black)
│   ├── svg/                ← Vector source files (.svg)
│   └── png/                ← Raster exports (.png at all sizes)
│
├── wallpapers/             ← Desktop background images
│   ├── official/           ← Default HENU OS wallpapers
│   │   ├── 4k/             ← 3840×2160
│   │   ├── 2k/             ← 2560×1440
│   │   └── fhd/            ← 1920×1080
│   ├── login/              ← GDM login screen background
│   ├── lockscreen/         ← Lock screen background
│   ├── installer/          ← Calamares installer backdrop
│   ├── grub/               ← GRUB bootloader background
│   └── plymouth/           ← Plymouth boot splash background
│
├── icons/                  ← Custom icon theme files
├── fonts/                  ← HENU OS brand typography (.ttf, .otf)
├── themes/                 ← GTK and shell themes
├── sounds/                 ← System notification and startup sounds
├── animations/             ← Lottie/animation files for splash screens
├── cursor/                 ← Custom cursor theme
│
├── grub/                   ← GRUB bootloader theme files
├── plymouth/               ← Plymouth boot animation theme
├── gdm/                    ← GDM login screen theme
└── installer/              ← Calamares/installer branding assets
```

---

## Naming Conventions

| Asset Type | Naming Pattern |
|---|---|
| Logos | `henu-logo-[variant]-[size].svg` |
| Wallpapers | `henu-wallpaper-[name]-[resolution].jpg` |
| Icons | Follow Freedesktop icon naming spec |
| Fonts | `HENUSans-[Weight].ttf` |
| GRUB theme | `henu-grub/theme.txt` |
| Plymouth theme | `henu-plymouth/` (folder) |
